# Roadmap

This is a short, living list of planned improvements. It is not a release promise.
Move completed items to [CHANGELOG.md](CHANGELOG.md) when they ship.

## Next

- Apply configured progression increments to gym-card weights when the recommendation is
  `increase weight`, and reduce the load when the recommendation is `reduce weight`.
- Include a concise hold/repeat cue in the gym card only when the progression is uncertain.

## Later

- Add an easy way to edit routine and exercise settings without manually changing TOML.
- Support additional Hevy routine configurations beyond the two configured PF routines.
- Add optional trend views for working-set volume, rep progress, and RPE.

## Ideas

Capture new ideas here as short bullets. Use GitHub Issues when an idea needs design discussion,
acceptance criteria, or implementation tracking.
